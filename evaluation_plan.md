# AI Model Evaluation for Technical Reasoning

## Project Objective
This project evaluates the accuracy, reliability, and technical reasoning of AI-generated answers to engineering questions.

## Evaluation Tasks
- Technical question answering
- Python code correctness
- Numerical and logical error detection
- Comparison of AI-generated answers with reference answers

## Evaluation Method
Each answer will be assessed using a reference answer and predefined evaluation criteria.

## Initial Domain
Electrical power systems and engineering simulations.

## Planned Metrics
- Factual accuracy
- Technical correctness
- Completeness
- Code correctness, where applicable
